==========================================
helpdesk_timesheet_exclude_from_sale_order
==========================================

Add exclude_from_sale_order field in ticket's timesheets

# Installation

Use Odoo normal module installation procedure to install
`helpdesk_timesheet_exclude_from_sale_order`.
